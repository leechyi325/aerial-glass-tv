# Aerial Glass TV 1.43-legacy.3 · Android 4.4 兼容预览版

本仓库的首个公开兼容预览版，重点适配 Android 4.4.2（API 19）。
基于上游 Aerial 1.43 的独立原生模块，不包含现代版的全部功能。

## 更新内容

- 玻璃底部托盘、16:9 应用磁贴、焦点放大和右侧玻璃菜单。
- 应用启动、置顶、隐藏、渐变或照片壁纸、时钟和 1080p H.264 航拍屏保。
- 修复已开启自启但开机接收器被禁用时，重启后无法启动的问题；设置开关和页面恢复时同步本应用组件状态。

## 下载和安装

| 文件 | 用途 |
| --- | --- |
| `aerial-glass-tv-1.43-legacy.3-standard.apk` | 普通版，声明 HOME，通常优先选择；已在海信 Android 4.4.2 上验证 |
| `aerial-glass-tv-1.43-legacy.3-guard.apk` | 不声明 HOME，供拒绝安装第三方桌面的固件试用；需要无障碍守护，尚未完成真机接管验证 |
| `SHA256SUMS.txt` | 两个 APK 的 SHA-256 校验值 |

两个版本最低均为 Android 4.4 / API 19，包名均为 `app.orchard.tv.legacy`，versionCode 为 3，不能同时安装。
与现代版 `app.orchard.tv` 可并存；应用内仍显示 Aerial 兼容版 / Aerial Legacy。

沿用本机此前真机测试的开发签名证书，本次发布的 APK 是 release 构建，未启用 debuggable。
证书 SHA-256：`fedccb8094667978580e44e23cdbd18d06f828671b325d58e19402dfb9deb69d`。
从此前同签名兼容版覆盖安装可保留设置；不要为升级而卸载或清除数据。
CI 自行生成的临时签名包可能无法覆盖本发布版。

首次安装后，自启和守护默认关闭，可按需要在设置中启用。不要停用系统原桌面。
安装、回退与功能边界见 [Android 4.4 兼容说明](../ANDROID44.md)。

## 验证与已知限制

- 普通版在海信 Hi3751 / Android 4.4.2 上已验证方向导航、底栏展开和收回、应用启动和返回、三轮屏保唤醒，以及真实重启后自启。
- H.264 航拍首帧已在该设备验证；尚未完成全部影片和长时间轮播测试。
- 玻璃效果从缓存的模糊壁纸采样，不是逐帧实时模糊。
- 守护版、其他机型、物理断电后启动和待机唤醒仍需单独验证。
- 两个版本 release 构建、严格 lint 与 Android 4.4 可用的 v1 签名校验通过。
- 暂不支持 Android 4.0–4.3；未移植手机配置页、天气、文件夹、4K/HDR 和自动升级。
